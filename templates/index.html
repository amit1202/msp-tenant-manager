What will be synced

  • For each MSP: verify account exists in SF, set parent to SDO - MSP
  • For each Tenant: find or create account, set parent to MSP account
  • Update License Pool & Licenses In Use with total active users
  • Check Active_production and Managed_By_MSP fields
  • Create / update License__c record per tenant

Status

License History Snapshot

Independent of the tenant list above — copies License Pool / Licenses In Use from every Salesforce Account flagged Active Production (including non-MSP accounts like on-prem customers) into a new daily License History record, then recomputes which record is latest for that account's week/month. This is what the daily routine runs automatically.
